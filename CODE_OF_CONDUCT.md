# Code of Conduct

## Our Pledge

We want this project to be a respectful, constructive place for users and
contributors.

## Expected Behavior

- Be respectful and professional.
- Assume good intent, but be precise.
- Focus on technical issues, not personal attacks.
- Give actionable feedback.

## Unacceptable Behavior

- Harassment or abuse
- Discriminatory language
- Personal attacks
- Publishing private information without permission
- Deliberately disruptive behavior

## Enforcement

Project maintainers may remove comments, reject contributions, or block access
for behavior that violates this code of conduct.

## Reporting

For conduct issues, contact the maintainer privately through the repository
owner account.
