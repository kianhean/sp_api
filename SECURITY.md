# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for security-sensitive problems.

Instead, report vulnerabilities privately to the maintainer through GitHub or
another private channel you already have with the maintainer.

When reporting, include:

- affected version or commit
- steps to reproduce
- impact
- any proof-of-concept details

## Scope Notes

This project interacts with private SP Services endpoints and Auth0 flows.
Please include any relevant endpoint behavior, callback URLs, or token-handling
details when reporting a problem, but avoid sharing real credentials or OTPs.
